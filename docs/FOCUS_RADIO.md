# Фоновое радио Васи

Один `QMediaPlayer` в процессе настольного виджета воспроизводит музыку. Скрытие виджета или закрытие окна Project OS не останавливает её. Запуск виджета никогда не включает музыку автоматически.

## Запуск

В каталоге проекта запустите виджет: `.venv/bin/python main.py`. Отдельно запустите API: `.venv/bin/python -m uvicorn apps.api.main:app --host 127.0.0.1 --port 8787`. Откройте `http://127.0.0.1:8787/control-center`. Управление доступно в блоке «Lo-fi радио», в трее и в контекстном меню персонажа.

Виджет и API должны использовать **один каталог данных**. При запуске из одного checkout это `storage/`; если один компонент упакован в `.app`, задайте обоим одинаковый `VASYA_APP_DATA_DIR`. API читает статус виджета и передаёт команды через локальный приватный каталог `focus_radio/`. При выключенном виджете API сообщает, что радио недоступно. Воспроизведение происходит на компьютере с виджетом, не на домашнем сервере.

Режим и громкость сохраняются в состоянии виджета, состояние воспроизведения не восстанавливается автоматически. Во время прослушивания микрофона радио приостанавливается; во время ответа голосом становится тише. После голосового взаимодействия возобновляется только включённое пользователем радио.

Аудио для «Ночь», «Ритм» и «Дождь» взято из собственного лендинга Vasya AI; «Тёплый» отрендерен из его последовательности аккордов в локальный WAV. Файлы включаются в сборку через существующее правило упаковки `assets/`.

Проверка: `.venv/bin/python -m unittest tests.test_focus_radio_bridge tests.test_api_focus_radio tests.test_focus_radio_player tests.test_avatar_tray_menu -v`. Тесты проверяют команды, доступность, маршруты и управление Qt; фактическое звучание, переключение устройства вывода и продолжение после закрытия окна требуют проверки на пользовательском Mac.
